# Roadmap

The detailed, phase-gated roadmap is maintained in [`docs/roadmap.md`](docs/roadmap.md). This root-level entry exists to make it discoverable from common repository landing pages and tooling.

Current priority is not a public product release: establish real Windows CI, implement and test the desktop/native-host integration and persistent queue, connect the UI to the engine, and run the full end-to-end path on Windows. Phase status and explicit exit gates remain in `docs/roadmap.md`; no item should be marked complete without evidence.
